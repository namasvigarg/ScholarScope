# 📘 AI Research Paper Assistant

A Streamlit-based app that allows users to:
- Upload research papers (PDFs)
- Generate AI summaries
- Ask questions using semantic search (FAISS + embeddings)
- View exact source chunks from PDFs

## 🚀 Features
- Multi-PDF upload
- AI-generated summaries
- Question answering with citations
- Chunk & page viewer
- Comparison of multiple papers

## 🛠 Tech Stack
- Streamlit
- PyMuPDF
- LangChain
- FAISS
- HuggingFace Embeddings
- OpenRouter API

## ▶️ How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
